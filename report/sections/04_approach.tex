\section{Approach}
\label{sec:approach}

Our method separates cheap textual retrieval from expensive multimodal localization. The key design choice is to use dense subtitle retrieval as a routing stage before \xml, while preserving \xml as the final cross-modal decision maker. In parallel, we evaluate text-only retrieval methods as baselines to measure how far cheap subtitle-based retrieval can go on its own. The main system claim in this report is based on VCMR, while SVMR is used to verify that routing preserves \xml's within-video localization behavior.

\subsection{Pipeline Overview}
The pipeline is evaluated in two modes. For the subtitle-window baselines, the input is a query, a known clip, its subtitle transcript, and precomputed clip-level features. We first build overlapping subtitle windows from the transcript, score them against the query, and return a ranked shortlist of candidate temporal regions. For \xml, retrieval is used at corpus level: dense subtitle matching produces a top-$k$ video shortlist, and official \xml inference localizes moments only within that retained set.

This design reflects the main bottleneck in the measured result. \xml is the component that performs cross-modal grounding, but full VCMR asks it to consider many candidate videos. A cheap routing stage can change that cost profile without pretending that text-only retrieval has solved temporal grounding.

\subsection{Subtitle-Window Retrieval Baselines}
We evaluate three text-first baselines over subtitle windows.

\paragraph{\bm retrieval.}
The lexical baseline indexes subtitle windows for each clip and ranks them with \bm. It is the cheapest method in the pipeline and provides a strong reference for how much signal is already available from transcript overlap alone.

\paragraph{Dense subtitle retrieval.}
The dense baseline encodes the query and subtitle windows with a sentence-transformer model and ranks windows by embedding similarity. This baseline tests whether semantic matching over subtitle text is more effective than lexical matching for TVR-style queries.

\paragraph{Fusion.}
We also evaluate lexical--dense combinations: weighted score fusion, reciprocal-rank fusion, and dense reranking over a \bm shortlist. In this project, these methods are treated as retrieval baselines and candidate generators. They are not the main modeling contribution, and in our experiments they do not account for the largest accuracy gains.

\subsection{Cross-Modal Localization with \xml}
\xml is the main multimodal localizer used in this work and serves as the strongest model in our study. In the official TVR setup, it consumes aligned video and subtitle features together with the language query, decomposes the query into modality-sensitive representations, contextualizes video and subtitle streams, and predicts start and end positions on the clip timeline. Its late-fusion design and start-end detector make it a strong reference point for multimodal moment retrieval on \dataset \cite{lei2020tvr}. The main system claim in this report is based on VCMR, while SVMR verifies that the routing stage preserves \xml's within-video localization behavior.

For this project, the important role of \xml is not that we redesign its internal architecture. Instead, we treat it as the high-quality localization model whose cost must be reduced. This is also why the text-only baselines are not sufficient by themselves: they can rank subtitle windows, but they do not replace cross-modal temporal grounding when visual evidence matters.

\subsection{Retrieval-Guided \xml Inference}
Our main adaptation is to use dense subtitle retrieval to control which videos \xml evaluates for VCMR. The retriever produces an external ranked video list for each query. During official \xml inference, that list is passed through the external retrieval path and the maximum number of VCMR videos is set to the chosen shortlist depth. The top-5 setting is the main operating point in this report.

Within each retained video, \xml still consumes the aligned video and subtitle features and predicts temporal start and end positions using its original localization machinery. Conceptually, this turns subtitle retrieval into a front-end router for multimodal localization: text narrows the candidate videos, and \xml performs the final cross-modal decision that drives the VCMR result.

This retrieval-guided formulation is the central idea of the project. It preserves the strengths of \xml while avoiding unnecessary multimodal scoring on videos that a much cheaper retriever can already rule out.
