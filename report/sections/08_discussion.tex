\section{Discussion}
\label{sec:discussion}

The main lesson from these experiments is that the largest systems gain comes from reallocating computation rather than from replacing multimodal localization with a stronger text retriever. Dense subtitle retrieval is useful because it cheaply improves corpus-level recall and decides where \xml should spend its budget. The multimodal stage is still doing the important localization work. This is visible in the validation results: dense $\rightarrow$ \xml top-5 improves VR and VCMR while preserving SVMR, which means the front-end is acting as a router rather than a substitute for cross-modal reasoning.

That interpretation also explains the main failure modes. Subtitle-first routing will remain fragile when the transcript is sparse, repetitive, or only loosely aligned with the decisive visual event. The subtitle-window baselines show that cheap text matching is useful, but not enough to solve temporal grounding by itself. The shortlist-depth ablation reflects the same trade-off at corpus level. Top-1 is fastest, but it is brittle because the entire pipeline depends on a very narrow candidate set. Top-5 is a better compromise because it keeps most of the speedup while making the routing stage less likely to discard the correct video before \xml has a chance to localize the moment.

Shared compaction is useful negative evidence. It shows that reducing the \xml sequence length is structurally feasible, but naive visual-change selection discards too much relevant context before multimodal relevance is resolved. In other words, the current repository benefits more from hierarchical video routing than from aggressive within-video compression. The main limitation of the present study is that it is still a validation-only analysis built around the available official features and local caches. Even after pruning, \xml localization remains the dominant validation-runtime term. The next question is therefore not whether retrieval should replace \xml, but how early visual evidence can enter the router without bringing back the full cost of exhaustive \xml inference.
