\section{Discussion}
\label{sec:discussion}

The main lesson from these experiments is that the best systems gain comes from reallocating computation rather than from replacing multimodal localization with a stronger text retriever. Dense subtitle retrieval is useful because it cheaply improves corpus-level recall and decides where \xml should spend its budget. The multimodal stage is still doing the important localization work. This is visible in the validation results: dense $\rightarrow$ \xml top-5 improves VR and VCMR substantially while preserving SVMR exactly, which means the front-end is acting as a routing mechanism rather than a substitute for cross-modal reasoning.

That interpretation also explains the main failure modes. Subtitle-first routing will remain fragile when the transcript is sparse, repetitive, or only loosely aligned with the decisive visual event. The large oracle gap in the clip-conditioned setting suggests that there is still considerable headroom between cheap text matching and the best possible temporal routing even before multimodal localization is applied. The shortlist-depth ablation reflects the same trade-off. Top-1 is fastest, but it is brittle because the entire pipeline depends on a very narrow candidate set. Top-5 is a better compromise because it keeps most of the speedup while making the routing stage less likely to discard the correct video before \xml has a chance to localize the moment.

The shared-compaction comparison is also informative. Its weaker results suggest that pruning inside a clip before multimodal relevance is resolved is riskier than pruning whole videos first and leaving the retained candidates intact. In other words, the current repo benefits more from hierarchical routing than from aggressive within-video compression. The main limitation of the present study is that it is still a validation-only analysis built around the available official features and local caches. In addition, even after pruning, \xml localization remains the dominant latency term. The most promising next steps are better learned routing, stronger retrieval encoders, and multimodal shortlist policies that use visual evidence earlier without reintroducing the full cost of exhaustive \xml inference.
