\section{Discussion}
\label{sec:discussion}

Use the discussion to interpret the results rather than repeat them. Good topics here include when subtitle-first retrieval fails, which query categories require visual evidence, what the latency bottlenecks are, and how much performance is left on the table by efficiency-driven simplifications.

If you want the report to read as CV plus systems rather than only as engineering, connect the failure modes back to modality usage and temporal reasoning. If you want it to read as systems plus CV, connect them back to cost models and pipeline structure.
